OUTPUTS AND MODEL PREPARATION

Each dataset folder contains train.jsonl and val.jsonl. v11 and v11s also contain
manifest.json and prompt_scaffold.json. Targets are strict A2UI Express v1.
Source/target text and chat messages are supplied; no model tokenizer is assumed.

The A2UI reference repository's training/scripts/run_golden_training.py accepts
these source-bound files via --input-dir. A model-specific preparation example
(not executed) is:

python D:\git\anup-code\A2UI\training\scripts\run_golden_training.py
  --profile e2b --model-dir <local-model-and-tokenizer-directory>
  --input-dir D:\git\GenUI-LM\training\data\train\v11
  --output-dir <fresh-training-run-directory> --prepare-only

Use v11s instead of v11 for the separate new-data-only training experiment.
In the GenUI-LM YAML training path, set run.dataset_dir to the appropriate
absolute dataset directory in a separate experiment config.
Do not pass these model-independent files as a sealed --prepared-input-dir;
the normal model-tokenizer preparation must still run. Its exclusions, if any,
must be reported separately from this model-independent corpus inventory.

For unseen performance after training on v11, evaluate v11s/val (2,229 rows).
v11s/train is included in v11/train. Both splits preserve their membership across
the two datasets. Do not combine train+val into an unseen evaluation benchmark.

See REVIEW_NOTES.txt for source-proven repairs, reassessment and reviewer limits,
source factual-review status, and the resulting new-only component distribution.

Exact reference policies, schemas, YAML configs, importer scripts and tests are preserved in policy_snapshot. The original reference checkout is read-only. Final output hashes are in each dataset manifest.
