Troubleshoot: Video Export

Resolving DaVinci Resolve Instability

Analyzing and resolving persistent crashes during Surface Tracker operations on Windows 11 environments. This clinical guide targets kernel-level and software-specific triggers.

info

System Assumptions

This troubleshooting path assumes use of **Resolve 18.5**. Environment monitoring shows no signs of thermal throttling or overheating. Configuration is treated as a baseline for high-performance workstation stability.

Step 1: Configuration

  • fiber_manual_record

    GPU Mode

    Switch to Manual and ensure "CUDA" is selected for NVIDIA hardware.

  • fiber_manual_record

    Fusion Cache

    Clear all render cache files and set Fusion RAM Cache to "Auto".

  • fiber_manual_record

    Optimized Media

    Regenerate optimized media if project resolution differs from source.

  • fiber_manual_record

    Software Version

    Verify build number 18.5 is consistent across collaborative DBs.

Step 2: Media & Integrity

Procedure check_circle

Isolate media files on a high-speed NVMe drive to rule out I/O bottlenecks during Surface Tracking.

Validation check_circle

Test a clean project with a single BRAW clip. If stability persists, the issue is likely global system configuration.

Step 3: System & GPU

settings_input_component

NVIDIA Studio Drivers

Install v536.40 or later. Use DDU for clean install.

Power Management

Set Windows Power Plan to 'High Performance'.
