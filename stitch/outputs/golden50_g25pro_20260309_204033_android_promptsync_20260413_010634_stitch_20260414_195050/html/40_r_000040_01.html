JavaScript Variable Declaration: var, let, and const

Understanding the mechanics of scope and hoisting in JavaScript isn't just academic—it's the bedrock of modern architectural integrity. These three keywords define how your data flows through the lifecycle of an application.

Core Characteristics

arrow_downward
Legacy Support

var

  • Scope: Function or Global.
  • Hoisting: Yes, initialized as undefined.
  • Re-declaration is permitted.
dentistry
ES6 Standard

let

  • Scope: Block-level.
  • Hoisting: No (Temporal Dead Zone).
  • Re-assignment is permitted.
lock
Immutable Reference

const

  • Scope: Block-level.
  • Hoisting: No.
  • Re-assignment: Not permitted.

Asynchronous Loops

A classic architectural pitfall occurs when using closures inside loops. The var keyword's functional scope often leads to unexpected behaviors.

The Problem with var error 
for (var i = 0; i < 3; i++) {
  setTimeout(() => {
    console.log(i); // Prints 3, 3, 3
  }, 1000);
}
The Solution with let check_circle 
for (let i = 0; i < 3; i++) {
  setTimeout(() => {
    console.log(i); // Prints 0, 1, 2
  }, 1000);
}
