Plan summary

Context used: one adult in America/Toronto timezone, daily meds at fixed times, and amoxicillin 500 mg every 8 hours from 2026-07-10 through 2026-07-17 inclusive.

Quiet hours are 22:00–06:30, so the antibiotic schedule is aligned to avoid overnight alerts.

The 8-hour antibiotic cadence is set to 06:30, 14:30, 22:00. On 2026-07-17, the final amoxicillin alert is 22:00.

Duplicate-notification prevention

Use a unique key per dose instance: user_id + medication + scheduled_datetime_local.

Do not send the base reminder if the dose was already marked taken early.

Do not send more than one snooze notification for the same dose at the same timestamp.

If app or device reconnects and retries queued pushes, suppress any notification whose dose status is no longer scheduled or snoozed.

If the user logs the same dose from two devices, first successful update wins; later duplicate events should be ignored.

For daylight-saving or timezone re-evaluation, store both local timezone: America/Toronto and resolved local scheduled datetime for each dose instance.
