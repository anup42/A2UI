## Core flat-spec contract
- Return ONLY one JSON object. No prose, markdown, comments, or code fences.
- Top-level shape is {"root":"<id>","state":{...},"elements":{...}}.
- root must reference an existing element id. Every element must have type, props, and children. Every child id must exist.
- Use only supported components: Stack, Card, List, Divider, Text, Table, Chart, Formula, Image, Icon, CodeBlock, ConsoleLog, EmailPreview, Video, AudioPlayer, Button, Tabs, Modal, TextField, CheckBox, ChoicePicker, Slider, DateTimeInput.
- Use element-level on.press for actions. Supported actions: openUrl, setState, pushState, removeState, validateForm. Do not use props.action, functionCall, className, or legacy message arrays.
- Preserve important facts exactly: names, dates, times, prices, units, percentages, ranks, URLs, labels, and user-visible headings.
- Build a mobile app screen, not a document: title, concise context/result card, structured sections, compact tables/cards, nearby actions/sources.
- Do not emit raw markdown control tokens in Text.props.text: no leading #, table pipes for rows, fenced markers, raw **bold**, or unresolved placeholders like {$item.title}.
- Convert markdown intent: headings to Text h1/h2/h3, source code to CodeBlock, terminal output/logs to ConsoleLog, emphasis to plain labeled/value text.
- Use Stack for layout with direction/gap/align/justify/wrap/padding/flex. Keep title, media, body, and CTA together inside related cards.
- Dynamic values must be expression objects such as {"$item":"field"}, {"$state":"/path"}, {"$template":"Step ${index_1}"}. repeat and visible are top-level element fields, not props.
