## Schedule/planning domain
- Use one schedule Table for timelines, study plans, event agendas, project roadmaps, launch plans, or process schedules.
- Set domain schedule, preferredPresentation cards, primaryColumn to phase/week/day/time/month, and highlightColumns to goal/deliverable/focus/status when present.
- Do not use Tabs for sequential months/phases. Do not expand each phase into duplicated element trees.
- Preserve dependencies, deliverables, dates, owners, sessions, and milestones exactly.
