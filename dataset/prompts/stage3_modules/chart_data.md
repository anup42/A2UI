## Chart/data domain
- For explicit chart/graph/visualization requests, emit a Chart backed by the same row data. Keep a compact Table when useful for exact values.
- Preserve numeric values, units, labels, categories, totals, percentages, axes, and time periods exactly.
- For survey/distribution percentage matrices, keep one compact Table; Android can render stacked percentage visuals from it.
- Do not use chart screenshots, random images, or decorative dashboard photos.
