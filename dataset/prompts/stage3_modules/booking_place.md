## Booking/place domain
- Use one compact Table with domain booking and preferredPresentation cards for hotels, venues, restaurants, local places, or options with ratings/prices/actions.
- Preserve name, location, distance, rating, price, availability, amenities, reason, and constraints.
- Put bookingUrl/actionUrl/sourceUrl and actionLabel in the same row. The CTA must render inside the matching card.
- Row image/photo fields are allowed only for verified media tied to that exact place. Do not create bottom galleries.
- Use source/action rows for global map/search links only when they are not row-specific.
