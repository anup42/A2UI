## Code/console domain
- Use CodeBlock for source code snippets and ConsoleLog for commands, terminal output, stack traces, REPL transcripts, expected output, and logs.
- Keep code and output separate unless output is part of a source-code comment.
- Preserve indentation, command flags, filenames, error messages, and line breaks.
- Do not render code/logs as oversized headings or prose. Do not duplicate the same snippet as text.
