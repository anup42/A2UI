TEDY is a token-efficient intermediate-representation framework for dynamic UI generation. The system receives a user query, generates a structured assistant response, converts that response into flat-spec GenUI/TEDY IR, validates and normalizes the IR, and renders it into native Android mobile UI.

The IR is intentionally semantic rather than pixel-level. It is one JSON object with root, state, and elements. root points to the entry element. state stores reusable structured data, including table rows, forecasts, flights, itinerary days, recommendation items, image assets, and action URLs. elements is a flat id-to-component map where components use semantic types such as Stack, Card, Text, Table, Image, Icon, Button, Tabs, Formula, CodeBlock, ConsoleLog, and EmailPreview.

The renderer owns platform fidelity. A compact Table in IR can render as daily weather cards in portrait, a true table in landscape, booking cards with row-level actions, flight cards, playlist rows, comparison cards, formula panels, email previews, or console/code blocks. Validation catches missing root, dangling child ids, invalid actions, bad table references, unsupported components, and media placement errors. Normalization repairs common model mistakes, canonicalizes table aliases, compacts expanded table trees, and emits diagnostics. The same contract supports metrics and response-to-IR training.
