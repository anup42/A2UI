Useful data fields available

These are the fields Android can route into richer native cards.

Flights

  • Airline name and airline logo
  • Departure/arrival airport ids, names, and times for each leg
  • Flight number, aircraft, travel class, legroom, extensions
  • Total duration, layover airport and duration
  • Price, price insights, historical price range
  • Carbon emissions vs typical route
  • Booking token for detail/booking continuation

Hotels

  • Name, description, hotel class, price per night, total rate
  • Overall rating, review count, star distribution, location rating
  • Scrollable property photos and photo detail endpoint
  • Amenities, nearby places, check-in and check-out time
  • Deals, property token, reviews/photos/detail links
  • GPS coordinates and official booking/website link

Sources: SerpApi Google Flights Search and SerpApi Google Hotels. API keys are not embedded in this HTML. Raw local test payloads were written to .tmp_mcp_flight_hotel/ and are intentionally not committed.
