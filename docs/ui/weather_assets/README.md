# Weather Assets

Reusable SVG asset set for the mobile weather day-card mockup in `docs/ui/weather_day_cards.html`.

## Contents

- `hero-showers.svg`: large hero weather mark.
- `day-showers.svg`, `rain.svg`, `partly-cloudy.svg`, `sunny.svg`, `cloudy.svg`, `thunderstorm.svg`, `fog.svg`: weather condition icons.
- `wind.svg`, `humidity.svg`, `uv-index.svg`, `temperature.svg`: metric icons.
- `umbrella.svg`, `advice-shield-check.svg`, `advice-bag.svg`, `advice-shirt.svg`: weather advice/action icons.
- `manifest.json`: IDs, filenames, roles, and tags for renderer/prompt references.

All SVGs are local, dependency-free, and use the same cyan/blue/teal/yellow weather palette as the mockup.
