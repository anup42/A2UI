Better ways to show 2-column and 3-column data

The best representation depends on semantics, not column count. These patterns keep IR compact as rows/columns while letting the renderer choose a mobile-first presentation.

Rule: do not expand a table into many text elements. Keep data as one compact table, then render as facts, timelines, entity cards, comparison matrices, or a real table based on shape and screen width.
